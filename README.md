# ProChat: AI-Powered Chatbot

![ProChat Screenshot](assets/images/screenshot.png)

ProChat is a responsive, user-friendly AI chatbot designed to assist users with real-time interactions. Built with modern web technologies and powered by the Google Gemini API, it offers a seamless chatting experience with features like chat history management and theme toggling.

## Features
- **Real-Time Chat**: Fetches AI responses using the Google Gemini API.
- **Chat History**: Stores and retrieves past conversations locally.
- **Responsive Design**: Adapts to all screen sizes with a clean UI.
- **Theme Toggle**: Switch between light and dark modes.
- **Editable Messages**: Users can edit sent messages with updated AI responses.

## Technologies
- **HTML5**: Structure of the chatbot interface.
- **CSS3**: Styling with custom gradients and animations.
- **JavaScript**: Core logic and API integration.
- **Google Gemini API**: Powers the AI responses.
- **Material Icons**: Enhances UI with iconography.
